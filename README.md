# W Gestión Inmobiliaria - Versión 2 (Avanzada)

> 🚀 **Estado de la Versión:** **En Desarrollo Activo / Nueva Fase de Funcionalidades**  
> ⚡ **Área de Trabajo Principal:** *A partir de este momento, todos los desarrollos, nuevas funcionalidades, módulos interactivos y expansiones de la plataforma se realizan de manera exclusiva en este repositorio y directorio.*

---

## 🎯 Propósito de la Versión 2
Esta versión toma como punto de partida el **Checkpoint 1 (Versión Básica)** y actúa como el entorno activo de desarrollo para la segunda etapa del proyecto:
- Implementación de nuevas funcionalidades avanzadas.
- Integraciones con APIs inmobiliarias, mapas interactivos y calculadoras financieras (ej. simulación hipotecaria en UF y dividendos en pesos chilenos).
- Módulo avanzado de administración y panel de control (Intranet).
- Optimizaciones de rendimiento, animaciones avanzadas y nuevas vistas interactivas.

---

## 🗂️ Estructura del Proyecto
- `index.html` / `landing.html`: Landing page principal (en desarrollo activo de nuevas funcionalidades).
- `servicios.html`: Flujo interactivo de servicios y procedimientos.
- `intranet.html`: Módulo de gestión y administración de activos.
- `server.js`: Servidor local Node.js.
- `assets/`: Galería de recursos multimedia, imágenes y gráficos vectoriales.
- `src/`: Código fuente complementario (React / TypeScript / Tailwind CSS).

---

## 🚀 Puesta en Marcha Local
```bash
# Iniciar servidor local
node server.js
```
El servidor responderá en `http://localhost:3600`.
